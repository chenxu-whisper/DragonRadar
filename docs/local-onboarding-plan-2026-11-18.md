## 冻结决定

- A1：无可读快照时禁用全局搜索，并可见显示“选择可读快照后可搜索发布归档”。有效快照保留现有搜索、Esc 与触发器焦点恢复。
- A2：PowerShell 7 在私有状态访问前，使用参数数组转交 Windows PowerShell 5.1。仅转交声明参数并传递退出码；保持 ACL、重解析点拒绝、端口、环境隔离和 worker 网络迁移。
- A3：仅 Reset 所有者构建增加取码命令、受保护文件位置、五分钟与一次性说明、失败重新取码指引。链接采用当前入口 origin；旧私人构建保持既有语义。页面不签发或读取配对码。

## 实施顺序

1. 前端 A1/A3：先新增浏览器失败断言，再最小修改；覆盖空快照恢复、拒绝清空、重复提交防护、会话恢复与显式退出。
2. 独立规格审查通过后，执行质量审查。
3. 脚本 A2：先用真实子进程与 PATH Docker 替身复现，再修改入口；测试两个宿主、入口、异常与退出码。
4. 独立规格审查通过后，执行质量审查。
5. 集中验证 TypeScript、前端单元、对应浏览器切片、五种构建预算及隔离、PowerShell、隔离 Compose 首次/重复启动、Ruff、compileall 与网关回归。
6. 更新使用文档与实测记录，按冻结哈希检查并同步指定文件回主工作区。
