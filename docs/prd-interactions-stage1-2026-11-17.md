# PRD 交互补齐：阶段 1 首个实施切片

依据：[下一阶段计划](next-development-plan-2026-11-17.md)、[57 项需求与 16 项扩展核对表](prd-interaction-audit-2026-11-17.md)。

本切片关闭优先级最高的指数详情、题材详情、总览每日 AI，以及记录判断后返回原页面的缺口。核对表中的其他交互缺口继续保留，不能将本切片标成全部 PRD 已完成。真实数据接入、正式研究输入、配对体验和生产验收保持各自原定阶段。

## 已实施行为

- 指数卡片打开独立只读抽屉，使用所选发布的指数价格、涨跌幅、成交额和 FAC-M03。缺失窗口与覆盖率逐项披露；当前发布没有指数历史行情归档，显示不可用原因。不会把指数当股票请求详情或比较。
- 题材热度与板块资金流打开题材抽屉，梯队导航作为独立操作保留。完整成员读取独立的发布物化块，分页绑定发布 ID、日期和题材 ID，展示分类／成员版本、生效期、可用时间、证据和成员覆盖。
- 题材成员进入证券详情时保留原题材、页码和触发入口；返回题材恢复成员焦点，退出恢复总览入口焦点。始终只存在一个打开的原生模态框。
- 总览每日 AI 仅存在于所有者 AI 构建。显式展开后预览当前发布的市场事实，再由用户显式生成任务；不读取或发送私人笔记、自选。复用任务取消、人工审核、事实／推断／缺失证据展示；采用结果新建独立笔记。
- 记录本地判断后提供返回市场总览、梯队、分析或消息的入口，保留原发布、日期和筛选。股票完整页进入笔记时继承原页面来源。

## 数据与兼容边界

公开题材详情是一条窄化只读路由，题材轮动仍保留原有公开访问边界。题材成员物化独立于角色候选；只在发布时生成，不在读取时重算。历史发布缺少新物化块时返回 `data: null` 和 `materialization_unavailable`；损坏归档拒绝服务。

没有成员完整性证据时，应有／已接收数量可为 `null`，页面显示“未知”，不能补零。发布 ID 与实际行情／题材输入 ID 分别展示，不混用。

当前发布未归档已审核的每日 AI，确定性事实模板继续存在。显式生成的任务是独立任务结果，人工审核状态另行展示；它不回写发布快照，也不自动成为公开页面速览。真实模型质量和生产效果不在本轮合成测试证明范围内。
