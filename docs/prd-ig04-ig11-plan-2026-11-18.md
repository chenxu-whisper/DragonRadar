# IG04–IG11 交互实施计划

> **For agentic workers:** 使用 subagent-driven-development，先规格复审再质量复审。用户已授权继续实施本批 PRD 交互；不提交、推送、合并或正式发布。

**Goal:** 关闭阶段 1 核对表中的 IG04–IG11，通过可复验交互连接现有发布事实、本地原创记录及所有者审核。

**Architecture:** 继续发布时物化，读取不可重算。历史列表以原锚点的发布序号水位选择实际历史发布；所有者审核独立于发布事实，本地验证独立于原始笔记修订。新能力按构建标志懒加载，公开入口仅可读取获准发布数据。

**Tech Stack:** React、TypeScript、FastAPI、PostgreSQL、IndexedDB、Playwright、Vitest、pytest、uv、Docker。

## 基线与工作边界

当前主工作区在 main，包含上一批和其他未提交工作。实施位置为项目外 `.temp/DragonRadar-IG04-IG11` 的 `feature/prd-ig04-ig11` 工作树，以当前有效源码复制建立基线；环境口令不复制。基线摘要为项目外 `ig04-ig11-baseline.json`，TypeScript 基线通过。回传只包含本批相对基线改变的文件，并检测主工作区并发改变。

临时脚本、日志、缓存与截图留在项目外 `.temp`。数据库测试仅使用一次性 `dragon_test`；各数据库不共享 fixture 会话，不向运行库添加数据。浏览器 RED 在所有测试文件就绪、产品源码未改时统一执行；GREEN 在全部源码冻结后统一执行，避免 Vite 热更新污染证据。

## 设计决策

- IG04：新增规范化的 `roles` 多选 URL 参数，保留旧 `role` 兼容。选择采用 OR 高亮；候选、状态与变动按角色分别显示，不累加重复证券或覆盖率。
- IG05：历史梯队显示实际历史发布中的股票，显示日期、发布 ID、规则版本和缺失原因。锚点热力图计数与历史发布的列表可能不同，分别披露。昨天固定池反馈详情在发布时归档，旧发布保留汇总但明确详情不可用。
- IG06：自选保存可选的历史名称、交易日、真实题材上下文；重复添加、删除／撤销保持原始身份和来源。旧记录解析原发布；不可解析不得改用当前发布。备份兼容旧格式并保留新上下文。
- IG07：显式确认笔记产生新修订。验证窗口请求起点为该修订交易日（基期），终点为该修订 verify_date；所选不可变验证发布须覆盖终点，实际日历调整起止逐项披露。记录验证发布 ID、请求／实际起止、发布日期／截至时间、来源／来源版本／规则版本，重开只读取该归档来源。人工写入 supported、weakened、refuted、not_due，修正通过 supersedes 追加。not_due 是未到期，不等同于缺失事实；缺失或未授权不能自动转成任何人工结论。禁止自动计算主观胜率。
- IG08：所有者读取每个实际 association_id 的独立关联复核状态，再按该状态的 revision 提交原 EX03 命令；读写与迟到响应绑定所有者、发布、文章及关联身份。409 保留用户决定与冲突提示，显式重新读取和重新确认；未知结果重试原幂等键。已接受／驳回审计和待新题材发布分别展示。公开快照成员及关联展示不变。
- IG09：个股详情可选择该发布中实际存在的角色题材，以该 sector 读取六组证据；正式监管事件打开同发布的该股实际事件。重复触发同股票切换关闭，任一时刻仅一个原生模态框。
- IG10：点击引用读取同所有者任务／草稿修订／发布的授权证据字段，并高亮实际字段值。定位由服务器基于不可变 manifest 验证；AI 处理许可不等同于来源片段显示许可，显示必须重新检查当前及归档授权、撤回状态。拒绝／撤权清除已展示片段，缓存与迟到响应不得恢复。不得从通用字符串猜文章 ID 或伪造段落范围，旧输入不能定位时显示原因。
- IG11：独立全局搜索按证券、题材、消息分组，查询所选发布的归档内容；不得将加载过的命令索引当完整搜索。成员表和搜索结果支持 20／50／100 分页，身份字段双向排序且空值置后。小型指标、固定六角色证据、有限日期矩阵不强行分页。

适用列表明确为：总览成员表、梯队每角色候选／变动表、题材成员、消息列表、涨幅排行、全局搜索结果、展开的行情历史数据表，默认 50，允许 20／50／100。身份／名称字段及实际存在的排名、收益、成交额字段按各自契约双向排序，空值置后；消息按既有发布时间排序契约，不任意改变消息排序语义。本轮保留指标汇总、有限日期／连板矩阵、固定六组角色证据、小型消息关联预览、原始笔记修订阅读面板的例外。已有题材、消息、排行分页用回归证明，不重复开发。
