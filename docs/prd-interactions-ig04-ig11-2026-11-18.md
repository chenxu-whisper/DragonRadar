## 实现与绑定

| 范围 | 当前行为 | 保留的缺失状态 |
| --- | --- | --- |
| IG04 梯队多角色 | `roles` 多选采用 OR 高亮，每个角色分别呈现候选、状态、覆盖与变动；角色卡片展示同发布行情、封板、题材与证据。候选及变动独立分页、排序。 | 观察角色不升级为正式候选；缺失封板时间、行情或角色输入单独说明。 |
| IG05 历史与固定池反馈 | 历史列表选择原锚点序号水位内的实际发布，点击股票打开其历史发布。固定昨天池、今日反馈、缺失和排除详情在发布时归档。 | 热力图锚点计数与历史发布列表分别披露；旧发布没有详情时保留汇总并说明归档不可用。 |
| IG06 上下文自选 | 保存实际证券名称、交易日和可选题材上下文，重开解析原始发布；删除、撤销、重复命令与备份维持原身份和来源。 | 旧记录无法解析原发布时拒绝替换为当前发布；名称或题材未知不补造。 |
| IG07 原判断与验证 | 确认产生新笔记修订；选定原确认修订后读取实际验证区间，并列显示原判断、证据、失效条件和行情事实。人工结论通过追加记录与 supersedes 修正。 | 缺失、错发布、未授权或不覆盖验证终点的事实不能成为人工结论；不计算主观胜率。 |
| IG08 关联复核 | 所有者读取实际关联的独立 revision，以原 EX03 命令确认或驳回。未知结果重试原幂等键；409 保留决定并要求显式重读和重新确认。 | 复核审计和待新题材发布分别显示，当前公开成员和关联事实保持不可变。 |
| IG09 个股证据 | 选择同发布实际角色题材，读取六组证据；展开该股同发布正式监管事件。历史与普通股票共用单个抽屉，支持重复触发关闭、Esc 和原来源返回。 | 错入口题材不触发证据读取；事件来源完整性未知不解释为零。 |
| IG10 引用定位 | 所有者按任务、草稿修订、发布和 evidence ID 读取服务端定位的实际授权字段，并高亮字段值。每次重开重新授权，关闭丢弃迟到响应。 | 旧输入不能定位时展示原因；AI 处理许可不能代替片段显示许可，撤权清除片段。 |
| IG11 搜索与列表 | 独立全局搜索使用所选发布的证券、题材、消息归档，各组独立说明状态。总览成员、角色表、搜索和展开行情使用 20/50/100 分页；实际身份及数值双向排序、空值置后。 | 缺归档区别于无匹配；现有命令面板维持命令用途，有限矩阵和固定六组证据不强制分页。 |

具体接口见 [workbench 契约](contracts/workbench-api.md)。公开、LOCAL、
所有者 AI 与旧私人构建按现有标志分离；本批不新增迁移。
