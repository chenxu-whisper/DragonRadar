# Task19 Option 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden the public Reset deployment with dependency-level sharing authorization, trusted client-IP forwarding, leak-free concurrency limiting, a genuinely public-only frontend bundle, and an immutable owner bind.

**Architecture:** `PublicationRepository` receives an access policy and remains local by default; the public facade uses the same repository with a fail-closed sharing policy and a publication-only lookup API. Caddy and ASGI share one fixed proxy trust contract, while the middleware uses structured ASGI control flow with exact-once slot release. A compile-time public flag removes local review, owner, and AI modules from the public dependency graph while leaving the private Reset build unchanged.

**Tech Stack:** Python 3.12, FastAPI/ASGI, SQLAlchemy/PostgreSQL, Caddy, Docker Compose, React 19, TypeScript, Vite 8, Vitest, Playwright, PowerShell.
