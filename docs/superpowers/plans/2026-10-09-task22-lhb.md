# Task 22 LHB Disclosure And Seats Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add authorized point-in-time LHB disclosures, immutable revisions, stable source-seat identities, null-safe buy/sell/net aggregation, EX08-09 read APIs, and a SecurityDetail seats panel without attributing source seats to natural persons.

**Architecture:** A new `dragon_radar.lhb` package owns strict source models, immutable disclosure storage, point-in-time revision selection, and pure seat aggregation. Public routes expose only authorized historical reads; the frontend validates source identity, units, null amounts, and synthetic/licensed labels. Migration `0012_lhb` extends the reviewed `0011_realtime` head and updates release/schema contracts without changing prior migrations.

**Tech Stack:** Python 3.12, Pydantic, SQLAlchemy Core, PostgreSQL 17, Alembic, FastAPI, React, TypeScript, Vitest, Playwright, pytest, Ruff, uv

- [ ] **Step 4: Implement `aggregate_seats`**

Use latest-visible revision per disclosure:

```python
def aggregate_seats(
    disclosures: Sequence[DisclosureRevisionInput],
    as_of: datetime,
) -> SeatAggregation:
    visible = [row for row in disclosures if row.available_at <= as_of]
    selected: dict[str, DisclosureRevisionInput] = {}
    for row in visible:
        current = selected.get(row.disclosure_id)
        if current is None or (row.revision, row.available_at) > (
            current.revision,
            current.available_at,
        ):
            selected[row.disclosure_id] = row
    return _aggregate_selected(tuple(selected.values()), as_of)
```

`_aggregate_selected` groups only by stable `seat_id`, retains contributing
disclosure/source identities, sums known values, and returns null net when any
required amount is unknown. Same display names with different IDs remain
separate rows.
