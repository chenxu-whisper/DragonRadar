## 范围与分层

本批交付市场总览、涨幅分析、单个证券抽屉及完整详情。React＋TypeScript 前端使用
已有 FastAPI、PostgreSQL 快照，不另算金融指标，不接真实供应商、不写笔记、不生成
角色排名、不输出监管认定、不启用公网分享。原始授权凭据不传到浏览器。

前端置于 `web/`；后端新增证券读模型，保持原 API 兼容。生产形态以 Caddy 托管
静态前端并同源代理只读 API；本批本机开发使用回环 HTTP，不宣称完成 PRD 的
HTTPS／所有者上下文或公网部署验收。工作台使用独立 Compose 项目，不修改首批实例。

## 证券读取契约

所有请求先由 `Repository.get_snapshot` 校验当前授权，再从该快照构造白名单字段。
证券集合仅限 `expected_security_ids`；历史状态按生效区间及 `available_at` 取值，
不倒灌未来名称。证券 ID 保持不变，名称不作主键。

- `GET /api/v1/snapshots/{id}/securities`：`q` 搜索名称或证券标识；
  `sort` 支持 `security_id/name/close/change/amount`，`order` 为 `asc/desc`；
  `page` 从 1 开始，`page_size` 仅 20／50／100，默认 50。
  `result` 包含 `items/total/page/page_size`，每项含证券 ID、当前名称、交易所、
  板块、收盘价、日收益、成交额、停牌和缺失原因。排序使用 Decimal 原值，
  空值无论升降序均在末尾，相同值按证券 ID 稳定排序。
- `GET /api/v1/snapshots/{id}/securities/{security_id}`：当前身份、价格、状态、
  该证券逐交易日历史。缺价与停牌保留空点和原因，不补零、不补假 OHLC。
  返回 `chart_type`：历史存在完整 OHLC 时可以提供 K 线，否则使用收盘线；
  缺失点始终中断。价格口径明确为原始价格，收益比较沿用复权价格。
- 现有快照摘要增加可选交易日历、证券身份读取需要的安全元信息，不暴露 grant 或归档。
  既有区间接口保持兼容；前端按其返回的共同 sessions 构图、显示实际窗口和排除原因。
- 每个响应沿用快照封装与版本清单，403 后立即清除可见受限数据，未知证券返回 404。
  不根据 Host／Forwarded 给予额外权限，不提供写入路由。

## 页面与交互

全局固定显示品牌、所选日期、版本、数据截至时间、来源与覆盖情况。历史日期无快照时
保留日期，显示无结果，不回退今天。首次进入可选择最新获授权已发布版本；版本选择器
区分修订与事后回补，不把 `contemporaneous` 标签当作已实现的历史截止选择功能。

市场总览展示同池广度、有效／缺失／停牌计数及证券列表，不展示尚不存在的指数或题材指标。
涨幅分析提供 N 日和自定义区间控件、排行、回撤、排除项及最多五标的归一化比较。
个股可单击打开抽屉，也可明确进入完整页面；抽屉使用原生 dialog、Esc 关闭并恢复焦点。
详情不提供虚假的角色、消息和风险结论。

筛选、排序、分页、视图、日期、快照、对比 ID 存入查询串；非法参数受控提示或规范化，
不造成崩溃。筛选变更回到第一页；返回列表恢复状态。切换快照清除不属于新快照的
选择和在途内容，请求必须带当前快照键，旧请求不可覆盖新请求。

请求有超时、取消及手动重试。初次加载使用结构占位，不造数；同条件刷新可以保留
旧数据并显示原时间，网络失败标记降级，授权失效清空内容。无 localStorage 持久化行情。
空库默认显示“暂无已发布快照”，不自动初始化虚构数据。
