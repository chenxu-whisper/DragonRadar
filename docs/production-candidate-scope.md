| --- | --- |

| 数据域 | market/state/calendar/benchmark；首轮不使用题材池或角色信号 |

| 对外范围 | 仅本机使用；没有公开目标、再分发或真实券商订单 |

首轮准备基准参数拟定为 Top-N=10、每5个交易日换仓、等权，
固定 random_seed=0。候选历史回测窗口目标为60个已完成官方交易日；
实际开始/结束日期必须由可认证的原始 PIT 数据和已发布快照确定。
若不足10只合格证券，必须保留既有内核的缺额/质量披露，不补造候选。

20 日因子每个决策时点至少需要21个同一 PIT 信息集内的完整证券及基准会话。
60个决策会话不能只提供60行价格；首个决策日也必须满足预热历史。
历史数据现在才首次取得时，不得补写过去的首次接收时间；
只有带原始当时接收证明的历史，才可用于对应历史 PIT 决策。

沪市主板范围须在真实供应商输入、冻结 pool 版本及发布快照中明确限定。
`UniversePolicy` 仅有 exclude_st/exclude_suspended/topic_ids，
不存在交易所/板块过滤字段；填写本模板不会添加运行时过滤。
未来装配运行前需核对逐日证券池确属所选范围，
不得把混合板块输入称为这个候选。
topic_ids 使用空集合，exclude_st/exclude_suspended 显式为 true。
退市证券的历史成交和既有持仓处理仍按内核契约保留。

## 拟定研究假设

以下仅为显式的研究模拟假设，不声称是真实券商报价或供应商批准的方法。
取得实际授权和规则后，须在冻结 BacktestConfig 中明确核对：

| 配置 | 拟定值 |
| --- | --- |
| commission_rate | `"0.0003"` |
| stamp_tax_rate / side | `"0.0005"` / sell |
| min_commission | `"5"` |
| slippage_model / rate | fixed_rate / `"0.001"` |
| fill_timing | next_tradable_point |
| unknown_limit_policy | reject_untradable |
| 成交价格 | raw；复权仅用于因子/收益计量，版本与口径须披露 |
| 成本敏感性 | 沿用内核 low/base/high 三档，不改计算阈值 |

成本、执行、策略和池定义必须一并进入真实冻结配置。
在取得适用官方规则与实际数据前，这些拟定值不能授权一次生产运行。
