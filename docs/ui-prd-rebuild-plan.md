# PRD 页面骨架恢复实施计划

**目标：**按开发需求 PRD §2.0、§3、§4 恢复页面结构、能力入口和正常/空数据状态。用户已于 2026-11-17 授权实施。

**架构：**保留六个主页面和单一个股抽屉；主导航使用完整产品名称。页面二级入口显式指向已有模块，不增加数据管理后台。无快照时展示各页面静态结构和原因，不请求依赖快照的分析，不生成数据。

**技术：**React、TypeScript、现有 ECharts、Playwright。继续从当前工作区开发；保留已有未提交工作，不提交、不发布。测试输出放到项目外的 `.temp`。

## 1. 骨架与导航

- 新增 `web/src/features/workbench/PageStructure.tsx`：集中声明主页面及二级模块入口，提供无快照页面骨架。
- 修改 `web/src/App.tsx`：完整主导航、二级模块入口、无数据骨架；模块定位保留日期/快照，遵循现有离开保护。
- 修改 `web/src/components/SnapshotHeader.tsx`：持续显示交易日、截至时间、股票池和质量状态；辅助来源和版本详情折叠。
- 修改 `web/src/features/review/PrivateApp.tsx` 和相关 CSS：改正会话文案，将会话工具与工作区视觉整合。
- UI 回归：无快照的五个读页面均有页标题和明确模块，跨页入口可用，不触发无上下文请求；移动宽度无横向溢出。

## 2. 总览布局

- 修改 `web/src/pages/Overview.tsx` 和懒加载的 `OverviewContent.tsx`：指数横条、涨停生态、三列概览、原始情绪曲线、题材排行/板块资金流、热力图、独立情绪研究区。
- 恢复 AI 每日速览区域：未提供已审核速览时展示快照事实模板，AI 操作仍只使用现有 owner 任务组件。
- 复用 `Chart`；缺指数、缺序列和缺资金流不能隐藏模块或补零；披露覆盖率和方法。
- 实时能力提供可见入口及选择提示，保留授权和输入校验。
- UI 回归：有合成快照时主要模块顺序、字段与图表可见，原有下钻/比较/导出仍有效。

## 3. 能力定位与复盘布局

- 消息：列表/详情、词云、题材建议入口；梯队：连板矩阵、角色候选、轮动入口。
- 涨幅分析：区间排行、比较、自然语言查询、研究回测入口；我的复盘：自选/笔记、AI 草稿、模拟组合入口。
- 龙虎榜入口定位到现有个股详情；没有证券时明确要求选择证券，不伪造独立全市场实现。
- 复盘主区保持自选与编辑并排，AI 草稿放在复盘区域，避免备份操作占据主要阅读层级。

## 4. 验证与运行

- 先新增 `web/tests/e2e/reset-page-structure.spec.ts`，运行并观察旧实现缺少页面骨架/完整导航的失败。
- 实施后运行新增用例及受影响 reset 市场、导航、消息、梯队、监管、复盘、偏好、研究、实时、龙虎榜用例。
- 运行前端单元测试和 TypeScript 检查；验证默认、reset、公开分享、私人、私人 AI 五种构建的包体隔离。
- 检查桌面和窄屏截图，再重建本机前端容器以供用户查看；保留正在使用的私人会话和数据库。
- 更新本文件记录实际验证结果。只有实际验证通过的范围才标为完成。

## 2026-11-17 实施与验证记录

页面结构已恢复：六个主页面使用完整名称，个股详情沿用独立页面／抽屉；侧栏恢复实时看盘、龙虎榜、题材轮动、自然语言查询、研究回测和模拟组合入口。公开分享构建保留五个读页面，并排除所有者研究和复盘入口。

总览恢复指数区、涨停生态、三列摘要、原始情绪序列、板块资金流和日期 × 板数热力矩阵。没有可用快照或单域物化不可用时保留模块标题、原因与定位目标；不补零或生成分析数据。AI 每日速览暂用明确标注的确定性快照事实模板。我的复盘恢复自选／笔记主区、AI 草稿与备份分区，模拟组合使用显式模块入口。

独立规格与质量复审发现的问题已修复：研究清单仅接受验证通过的快照；龙虎榜保留模块上下文；模块定位跟踪懒加载及占位替换；模拟账本未保存输入和持久化操作受离开保护；修饰键点击保留浏览器链接语义。移动端交互命中区至少 44px，涨停生态定义列表结构通过 axe 检查。
