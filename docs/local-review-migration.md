# 本地复盘迁移与备份

旧版 PostgreSQL 私人复盘数据可导出为本地 JSON，再由重置版工作台导入浏览器
IndexedDB。迁移不会删除旧服务端数据，也不会关闭旧接口。

## 从旧服务导出

先配置旧服务使用的 `DRAGON_DATABASE_URL`，再执行：

```console
dragon-radar owner-export \
  --local-profile-id <目标浏览器资料标识> \
  --output <新文件路径>.json
```

目标文件必须不存在。命令以受保护权限创建文件且不会覆盖已有文件。标准输出只包含
文件路径和记录计数，不包含复盘正文。

导出范围仅限 `owner_principals.local_key = 'local'` 的以下数据：

- 用户填写的笔记文本及全部修订；
- 验证记录及其修订引用；
- 自选记录；
- 上述记录引用的笔记、修订、快照和证券标识。

导出器在一个 PostgreSQL `READ ONLY, REPEATABLE READ` 事务中读取owner、笔记、
修订、验证和自选，保证各数组来自同一数据库快照。

导出不包含行情事实、行情数据、文章正文、Cookie、会话、密钥、配对码、CSRF、
令牌、凭据、命令日志或审计日志。旧字段 `invalidation` 和
`verification_date` 分别转换为 `invalid_condition` 和 `verify_date`；旧笔记没有
正文时，`content` 为 `""`。

## 格式版本 1

格式尚未对外发布，因此仍使用 `format_version: 1`。本版本的笔记元数据精确字段为
`note_id`、`snapshot_id`、`trade_date`、`security_id`、`current_revision`、
`created_at`、`updated_at`；其中旧服务导出的 `trade_date` 是
`review_notes.trade_date` 的 ISO 日期。浏览器中新建但没有日期上下文的草稿可导出
`trade_date: null`，已确认修订不允许缺少该日期。除明确加入 `trade_date` 外，各层
对象仍执行精确键校验。

导入上限为：文件 UTF-8 字节数 8 MiB；任一记录数组 5,000 条；四类记录合计
10,000 条；标识符 200 个字符；时间戳 64 个字符；标题 100 个字符；正文、判断、
依据、失效条件及验证依据各 20,000 个字符。浏览器先依据 `File.size` 拒绝超限文件，
不会调用 `file.text()`；解析器在规范化和规划前再次检查字节数及记录数。

## 在浏览器恢复

1. 打开重置版工作台的“我的复盘”。
2. 在“备份与恢复”中选择 JSON 文件。文件仅在浏览器本地读取，不会上传。
3. 检查预览中的重复项、追加修订、标识重映射和未解决冲突。
4. 明确选择“合并到同名笔记”或“全部另存为新笔记”。
5. 仅在未解决冲突为零时执行恢复。

浏览器会先验证完整文件，再规划导入，最后开启一次覆盖所有相关对象仓库的
IndexedDB 写事务。执行恢复使用用户刚确认的不可变预览计划；如果本地数据在预览后
发生变化，恢复会要求重新预览。文件损坏、引用不完整、计数不符、存储失败、预览
过期或未解决冲突都会使整次导入失败，不会留下部分写入。

已确认修订必须有非空判断、依据和失效条件，必须有不早于笔记 `trade_date` 的
`verify_date`。验证只能引用同一笔记的已确认修订。`supported`、`weakened` 和
`refuted` 必须有非空依据和非空 `snapshot_id`；`not_due` 必须使用
`snapshot_id: null`。历史 `not_due` 记录不与导入当天日期比较。

## 合并规则

- 现有修订不会被替换或删除。
- 仅当来源资料、来源修订标识、状态和规范化内容都相同时，修订才视为重复。
- 相同文本的草稿与已确认修订，以及来自不同来源资料的同文修订，都会保留为独立
  本地修订。
- 不同的备份修订按原备份顺序追加在当前修订之后；验证记录自动指向追加后的本地
  修订号。
- “另存为新笔记”按稳定来源资料标识、当前本地资料和原笔记标识确定性生成新标识，
  不依赖导出时间、文件哈希或随机 UUID；同一来源的后续导出仍映射到同一笔记。
- 对同一备份重复执行相同决策不会新增笔记、修订、验证或自选。
- 同键但内容不同的验证或自选记录会显示为未解决冲突，且不会写入。

## 日常本地备份

点击“导出本机备份”可直接下载当前 IndexedDB 中的完整本地复盘 JSON。文件包含
`format_version`、`exported_at`、明确的 `owner_id -> local_profile_id` 映射，以及
笔记、修订、验证和自选计数。建议在清理浏览器网站数据或更换浏览器前导出，并在
恢复后核对计数和每个修订版本。
